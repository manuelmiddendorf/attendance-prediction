# Data

This repository does not contain the original attendance data used during development.

Only synthetic datasets are included for reproducibility and demonstration purposes. They are generated from a statistical model calibrated to coarse aggregate properties of the private data and contain newly simulated members, classes, and booking histories rather than pseudonymized source records.

Directory structure:

- `synthetic/` — synthetic datasets used in the notebooks
- `raw/` — ignored (original data)
- `processed/` — ignored (derived from original data)
